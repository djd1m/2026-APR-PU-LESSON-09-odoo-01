## C. 10x IMPROVEMENT

> **Автоматическая фиксация этапов ремонта через AI-камеры** — то, чего нет ни в 1С, ни в существующих CRM для ремонта. Computer Vision распознаёт: штукатурка нанесена → стяжка залита → трубы смонтированы → и автоматически обновляет Gantt-диаграмму. Заказчик видит прогресс в реальном времени без звонков прорабу.

**Источник:** Аналог для строек — [OpenSpace](https://build.inc/insights/ai-construction-monitoring-cre), [Buildots](https://duckviewsystems.com/ai-construction-cameras/), но для квартирного ремонта таких решений НЕТ.
