# RemontERP -- Документация

**Odoo 19 ERP для управления ремонтом квартир с AI-камерами.**

RemontERP -- вертикально интегрированная платформа на базе Odoo 19 Community Edition, объединяющая ERP-систему с AI-камерами для автоматического отслеживания этапов ремонта, генерации таймлапс-видео и прозрачного клиентского портала.

## Стек технологий

| Компонент | Технология | Версия |
|-----------|-----------|--------|
| Backend | Python + Odoo ORM | 3.12 / 19.0 |
| Frontend | OWL.js (Odoo Web Library) | 2.x |
| База данных | PostgreSQL | 16 |
| Очередь / Кэш | Redis | 7 |
| Хранилище объектов | MinIO (S3-совместимое) | latest |
| CV-модель | YOLOv8 (Ultralytics) | 8.x |
| Видеообработка | FFmpeg | 6+ |
| Reverse Proxy | Nginx | 1.25+ |
| Платежный шлюз | ЮKassa API | v3 |
| Контейнеризация | Docker + Docker Compose | 24+ / 2.x |
| Инфраструктура | VPS (AdminVPS/HOSTKEY) | -- |
