# Руководство пользователя

Пошаговая инструкция для конечных пользователей RemontERP: владельцев квартир, подрядчиков и рабочих.

---

## 1. Регистрация и вход

### Регистрация

1. Откройте портал RemontERP по адресу `https://erp.example.com/portal`
2. Нажмите **"Зарегистрироваться"**
3. Заполните форму:
   - **Email** (уникальный, будет использоваться для входа)
   - **Пароль** (минимум 8 символов, минимум 1 заглавная буква, минимум 1 цифра)
   - **Имя** (полное имя)
   - **Телефон** (опционально)
4. Подтвердите email по ссылке из письма
5. Войдите в систему

> **Примечание:** При регистрации вам автоматически присваивается роль "Наблюдатель" (viewer). Для получения расширенных прав (владелец, подрядчик) обратитесь к администратору.

`[Скриншот: форма регистрации с полями email, пароль, имя, телефон]`

### Вход в систему

1. Перейдите на страницу входа
2. Введите email и пароль
3. Нажмите **"Войти"**

Авторизация происходит через защищенные httpOnly-куки. Токены никогда не сохраняются в браузере (localStorage/sessionStorage).

## 2. Создание проекта ремонта

1. Перейдите в раздел **"Мои проекты"**
2. Нажмите **"Создать проект"**
3. Заполните информацию:
   - **Название** (например, "Ремонт на Тверской, 15")
   - **Адрес** квартиры
   - **Площадь** (кв.м)
   - **Тип** (новостройка / вторичка)
   - **Плановая дата начала** и **дата окончания**
   - **Бюджет** (предварительная оценка)
4. Нажмите **"Сохранить"**

## 3. Подключение камеры

### Поддерживаемые камеры

- Wyze Cam v4
- TP-Link Tapo C220
- Любая камера с поддержкой RTSP

### Подключение

1. Откройте проект
2. Перейдите на вкладку **"Камеры"**
3. Нажмите **"Добавить камеру"**
4. Введите:
   - **RTSP URL** камеры (например, `rtsp://192.168.1.100:554/stream1`)
   - **Название** (например, "Кухня", "Гостиная")
   - **Интервал съемки** (по умолчанию: каждые 15 минут, диапазон: 5-60 минут)
5. Система проверит доступность камеры и покажет превью-кадр
6. Нажмите **"Подключить"**

> **Ограничения:** Тариф Free -- 1 камера, Pro -- до 4 камер, Enterprise -- без ограничений.

## 5. Таймлапс-видео

### Ежедневный таймлапс

Каждый день в 02:00 система автоматически генерирует 30-секундное видео из всех снимков за предыдущий день:

- Формат: MP4 (H.264, 1080p, 30 fps)
- Хранится в MinIO и доступно через портал
- Можно просмотреть прямо в браузере через встроенный плеер

`[Скриншот: встроенный видеоплеер с таймлапсом дня]`

### Пользовательский таймлапс

Вы можете запросить таймлапс за произвольный период (до 30 дней):

1. Перейдите в раздел **"Таймлапсы"**
2. Выберите период (дата начала -- дата окончания)
3. Нажмите **"Сгенерировать"**
4. Видео будет готово в течение 5 минут

### Поделиться таймлапсом

1. Откройте таймлапс
2. Нажмите **"Поделиться"**
3. Выберите способ:
   - **Ссылка** -- публичный URL (действует 7 дней)
   - **Telegram** -- отправка через Telegram-бота
   - **Instagram** -- скачивание в формате 1080x1080 (квадрат) или 9:16 (вертикальный)
4. На видео автоматически добавляется водяной знак RemontERP

> **Реферальная ссылка:** В каждую публичную ссылку встраивается ваш реферальный код. Если по ней зарегистрируется новый пользователь, вы получите бонусные дни.

`[Скриншот: диалог "Поделиться" с вариантами ссылка/Telegram/Instagram]`

## 6. Управление бюджетом

### Создание сметы

1. Откройте проект
2. Перейдите на вкладку **"Бюджет"**
3. Нажмите **"Создать смету"**
4. Добавьте позиции по категориям:
   - **Материалы** (плитка, краска, провода и т.д.)
   - **Работа** (оплата бригады, отдельных специалистов)
   - **Оборудование** (аренда инструмента)
   - **Накладные** (доставка, вывоз мусора)
5. Укажите плановую сумму для каждой позиции

> **Точность:** Все финансовые расчеты выполняются с точностью DECIMAL(12,2). Система никогда не использует числа с плавающей запятой для денежных операций.

`[Скриншот: форма создания сметы с категориями и суммами]`

### Отслеживание расходов

1. Перейдите на вкладку **"Расходы"**
2. Нажмите **"Добавить расход"**
3. Укажите:
   - Категорию
   - Сумму
   - Описание
   - Фото чека (опционально)
4. Система автоматически пересчитает отклонение факт/план

### Индикация бюджета

| Цвет | Значение |
|------|----------|
| Зеленый | Расходы в пределах сметы |
| Желтый | Израсходовано более 80% бюджета категории |
| Красный | Перерасход -- расходы превысили смету |

### Оповещения о бюджете

Система автоматически уведомляет (через портал и Telegram) при:
- Расходовании более 80% бюджета по категории (предупреждение)
- Превышении 100% бюджета по категории (критическое)

## 7. Уведомления

### Настройка каналов

1. Перейдите в **"Настройки" > "Уведомления"**
2. Выберите каналы:
   - **Telegram** (укажите Telegram-чат)
   - **Email**
   - **Браузер** (Web Push)
3. Выберите частоту:
   - **Мгновенные** -- сразу при событии
   - **Дайджест** -- сводка раз в день в 20:00
   - **Выключены**

### Типы уведомлений

| Событие | Описание |
|---------|----------|
| Смена этапа | AI обнаружил переход на новый этап ремонта |
| Таймлапс готов | Ежедневное видео доступно для просмотра |
| Бюджет 80% | Предупреждение о приближении к лимиту |
| Перерасход | Расходы превысили смету |
| Бригада отсутствует | Нет активности на объекте более 48 часов |
| Задержка графика | AI предсказывает задержку более 3 дней |

> **Лимит:** Максимум 20 уведомлений в день на пользователя. Сверхлимитные уведомления включаются в дайджест следующего дня.

## 8. Реферальная система

### Как это работает

1. В вашем профиле есть уникальный 8-символьный реферальный код
2. Код автоматически встраивается в ссылки при шаринге таймлапсов
3. Когда новый пользователь регистрируется по вашей ссылке и оформляет подписку Pro:
   - **Вы** получаете **14 бесплатных дней** подписки
   - **Приглашенный** получает **7 бесплатных дней**

### Ограничения

- Максимум 10 реферальных вознаграждений в календарный месяц
- Вознаграждение начисляется только при оформлении платной подписки

### Реферальная панель

В разделе **"Рефералы"** отображается:
- Общее количество приглашений
- Успешные конверсии (подписки)
- Заработанные бонусные дни
