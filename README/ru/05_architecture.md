## 2. Поток данных

### Захват и обработка снимков

```
Камера (RTSP)
    |
    v
FFmpeg Worker --> Снимок (JPEG, quality 85)
    |
    +---> MinIO: /{project_id}/{camera_id}/{YYYY-MM-DD}/{HH-MM-SS}.jpg
    |
    +---> PostgreSQL: метаданные (timestamp, camera_id, path, size)
    |
    +---> Redis Queue: задача на CV-обработку
              |
              v
        CV Worker (YOLOv8)
              |
              +---> PostgreSQL: результат классификации (этап, уверенность, версия модели)
              |
              +---> Odoo JSON-RPC: обновление этапа проекта (если уверенность >= 0.65)
```

### Генерация таймлапса

```
Cron (02:00 ежедневно)
    |
    v
Redis Queue: задача на генерацию таймлапса
    |
    v
Timelapse Worker
    |
    +---> MinIO: загрузка снимков за день
    |
    +---> FFmpeg: генерация MP4 (H.264, 1080p, 30fps, ~30 сек)
    |
    +---> MinIO: сохранение /{project_id}/{camera_id}/timelapse/{YYYY-MM-DD}.mp4
    |
    +---> Odoo JSON-RPC: создание записи таймлапса
    |
    +---> Уведомление пользователю (Telegram / email / Web Push)
```

### Поток оплаты

```
Пользователь --> Выбор тарифа --> Odoo --> ЮKassa API (создание платежа)
                                              |
                                        ЮKassa Checkout
                                              |
                                        ЮKassa Webhook --> POST /api/v1/webhooks/yukassa
                                                              |
                                                        Проверка HMAC-SHA256
                                                              |
                                                    +-------- + --------+
                                                    |                   |
                                              Валидная              Невалидная
                                              подпись               подпись
```

## 5. Модель безопасности

### Ролевая модель (RBAC)

| Роль | Свои данные | Все данные | Редактирование | Администрирование |
|------|:----------:|:----------:|:--------------:|:-----------------:|
| viewer | Да | Нет | Нет | Нет |
| owner | Да | Нет | Свои проекты | Нет |
| contractor | Да | Назначенные | Назначенные | Нет |
| worker | Да | Нет | Нет | Нет |
| admin | Да | Да | Да | Да |

### Правила безопасности

1. **Регистрация без ролей** -- поле `role` в запросе на регистрацию игнорируется, всегда назначается `viewer`
2. **JWT в httpOnly-куках** -- токены никогда не доступны JavaScript (защита от XSS)
3. **Аварийная остановка при отсутствии секретов** -- приложение не запустится без `JWT_SECRET`, `YUKASSA_SECRET_KEY` и других обязательных переменных
4. **HMAC-верификация вебхуков** -- все вебхуки ЮKassa проверяются через `hmac.compare_digest()` (защита от timing-атак)
5. **Decimal для денег** -- все финансовые расчеты используют `NUMERIC(12,2)` и Python `Decimal`, никогда `float`
6. **Валидация ввода** -- все данные пользователя проходят через DTO, используется ORM Odoo (защита от SQL-инъекций), QWeb экранирует HTML (защита от XSS)
7. **152-ФЗ** -- данные хранятся на серверах в России, согласие на обработку при регистрации

### Шифрование

| Тип | Реализация |
|-----|-----------|
| В транзите | TLS 1.2+ для всех внешних коммуникаций |
| Пароли | PBKDF2-SHA512 (Odoo passlib) |
| В покое (опционально) | PostgreSQL TDE, MinIO server-side encryption |
