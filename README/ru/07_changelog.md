## [0.1.0] -- 2026-05-26

Первоначальный релиз MVP. Реализованы 10 основных функций платформы.

### Добавлено

1. **Модуль камер** (`remont_camera`)
   - Подключение AI-камер по RTSP
   - Захват снимков каждые 15 минут (интервал настраивается: 5-60 мин)
   - Хранение снимков в MinIO (S3-совместимое хранилище)
   - Поддержка до 4 камер на проект (зависит от тарифа)
   - Мониторинг статуса камер (онлайн/офлайн/ошибка)

2. **CV-пайплайн** (`remont_cv` + `cv_worker`)
   - Автоматическое определение этапа ремонта на основе YOLOv8
   - Классификация 8 этапов: демонтаж, электрика, сантехника, штукатурка, стяжка, плитка, покраска, отделка
   - Целевая точность >= 70%
   - Отметка снимков с низкой уверенностью для ручной проверки
   - Автоматическое обновление этапов проекта через JSON-RPC

3. **Генератор таймлапсов** (`remont_timelapse` + `timelapse_worker`)
   - Ежедневная генерация 30-секундных видео (MP4, H.264, 1080p, 30fps)
   - Генерация по запросу за произвольный период (до 30 дней)
   - Публичные ссылки для шаринга (срок действия 7 дней)
   - Водяной знак RemontERP
   - Форматы для Instagram (1080x1080 и 9:16)

4. **Клиентский портал** (`remont_portal`)
   - Таймлайн ремонта с фотогалереей
   - Фильтрация снимков по этапам и датам
   - Встроенный видеоплеер для таймлапсов
   - Виджет бюджета (план vs факт)
   - Адаптивный дизайн (mobile-first)
   - Ленивая подгрузка (20 снимков за прокрутку)

5. **Управление проектами** (`remont_core`)
   - Диаграмма Ганта с этапами ремонта
   - Drag-and-drop перепланирование задач
   - Чеклисты для каждого этапа
   - Управление несколькими проектами одновременно
   - Назначение бригад и рабочих на этапы

6. **Трекер бюджета** (`remont_billing`)
   - Создание смет по категориям (материалы, работа, оборудование, накладные)
   - Ввод фактических расходов с фото чеков
   - Сравнение план/факт с цветовой индикацией
   - Все финансовые расчеты на DECIMAL(12,2), без float
   - Экспорт отчетов в PDF/XLSX

7. **Авторизация и управление пользователями** (`remont_auth`)
   - Регистрация по email (поле role игнорируется, по умолчанию viewer)
   - JWT в httpOnly, Secure, SameSite=Strict куках
   - Ролевая модель: viewer, owner, contractor, worker, admin
   - Назначение ролей только через админ-панель
   - Аварийная остановка при отсутствии JWT_SECRET
   - Валидация всех обязательных env-переменных при старте

8. **Интеграция с ЮKassa** (`remont_billing`)
   - Подписочные платежи через ЮKassa API v3
   - HMAC-SHA256 верификация вебхуков (constant-time comparison)
   - Идемпотентная обработка повторных вебхуков
   - Тарифы: Free, Pro, Enterprise
   - Грейс-период 3 дня после окончания подписки
   - Автопродление через сохраненные способы оплаты

9. **AI-оповещения** (`remont_alerts`)
   - Обнаружение отсутствия бригады (нет активности 48+ часов)
   - Предупреждения о перерасходе бюджета (80% и 100%)
   - Уведомления через Telegram, email, Web Push
   - Настраиваемая частота: мгновенные, дайджест, выключены
   - Cooldown 4 часа между повторными алертами

10. **Реферальная система** (`remont_referral`)
    - Уникальный 8-символьный реферальный код для каждого пользователя
    - Реферер получает 14 бонусных дней, приглашенный -- 7 дней
    - Код встраивается в ссылки шаринга таймлапсов
    - Лимит: 10 вознаграждений в календарный месяц
    - Реферальная панель со статистикой

### Инфраструктура

- Docker Compose с 7 сервисами (Odoo, PostgreSQL, Redis, MinIO, Nginx, CV Worker, Timelapse Worker)
- Nginx с SSL-терминацией (Let's Encrypt)
- Деплой на VPS (AdminVPS/HOSTKEY)
- Соответствие 152-ФЗ (данные на серверах в РФ)

### Безопасность

- JWT исключительно в httpOnly-куках (никогда в localStorage)
- HMAC-SHA256 верификация вебхуков с constant-time comparison
- Fail-fast при отсутствии секретов (JWT_SECRET, YUKASSA_SECRET_KEY и др.)
- DECIMAL для всех финансовых расчетов (никогда float)
- Валидация ввода через Odoo ORM (защита от SQL-инъекций)
- QWeb экранирование (защита от XSS)
- Rate limiting на эндпоинтах регистрации и вебхуков
